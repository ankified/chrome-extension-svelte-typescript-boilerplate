O projeto atual é uma extensão para navegadores baseados em Chromium construída usando Svelte 5, TailwindCss 4, Shadcn-Svelte e WXT. Ela tem como funcionalidades salvar páginas como Bookmarks, sincronizar com o Google Drive e exibir os itens salvos com os detalhes pertinentes.
Quero que você analise a estrutura do projeto, as estruturas de dados e os fluxos de criação, sincronização e exibição de bookmarks para entender como o projeto está implementado e, quando você tiver entendido tudo, darei mais instruções.
