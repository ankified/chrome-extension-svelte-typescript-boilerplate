### 17:02:34
- Corrigida a filtragem por grupos e tags na tabela de itens salvos (`DataTable.svelte` e `columns.ts`).
- **Motivo do problema:** O TanStack Table só aplica filtros de coluna se o estado `columnFilters` for controlado e atualizado via `onColumnFiltersChange`. O projeto não estava controlando esse estado, então mesmo ao chamar `setFilterValue` nos dialogs de filtro, a tabela não aplicava o filtro.
- **Solução aplicada:**
   - Adicionado o estado reativo `columnFilters` usando `$state` em `DataTable.svelte`.
   - Passado esse estado para o TanStack Table via a opção `state: { get columnFilters() { return columnFilters; } }`.
   - Implementado o handler `onColumnFiltersChange` para atualizar o estado local sempre que o TanStack Table modificar os filtros.
   - Com isso, ao chamar `table.getColumn('groupIds')?.setFilterValue(...)` ou `table.getColumn('tags')?.setFilterValue(...)`, o filtro é corretamente aplicado e a tabela é re-renderizada.
- **Arquivos modificados:** `src/options/views/table/DataTable.svelte`, `src/options/views/table/columns.ts`.
- **Orientação para futuras correções:**
   - Sempre que a filtragem por coluna do TanStack Table não funcionar, verifique se o estado `columnFilters` está sendo controlado e passado corretamente para a tabela, e se o handler `onColumnFiltersChange` está implementado.
   - O método correto para aplicar filtros programaticamente é `table.getColumn('nomeDaColuna')?.setFilterValue(valor)`, mas isso só terá efeito se o estado for controlado.
- **Próximos passos planejados:**
   - Corrigir e aprimorar a filtragem por data de criação.
   - Implementar ações em lote e paginação na tabela.
   - Refinar a experiência visual e responsiva da tabela.
