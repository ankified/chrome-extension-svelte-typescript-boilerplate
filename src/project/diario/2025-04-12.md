# Diário de Desenvolvimento - 2025-04-12

### 13:47:16
- **Correção:** Resolvido problema de layout nos diálogos de filtro de Tags e Grupos onde as abas "Incluir" e "Excluir" eram exibidas simultaneamente.
- **Causa:** Classes de layout Flexbox (`flex-grow`, `overflow-hidden`, `flex`, `flex-col`, `mt-2`) aplicadas diretamente aos componentes `<Tabs.Content>` estavam interferindo na lógica de visibilidade interna do componente `<Tabs.Root>`.
- **Solução:** Removidas as classes de layout mencionadas dos elementos `<Tabs.Content>` em ambos os diálogos.
- **Arquivos modificados:** 
  - `src/options/components/TagFilterDialog.svelte`
  - `src/options/components/GroupFilterDialog.svelte`
- **Próximos passos planejados:**

### 13:53:34
- **Correção:** Resolvido problema de layout na visualização principal de Itens Salvos (`SavedItemsView.svelte`) onde as abas de visualização (Tabela, Cartões, etc.) eram exibidas empilhadas.
